# 水表测试配置文档

## 一、测试模式

### 适用产品：
- 超声波水表
- 有阀门（5线阀门）
- 无阀门
- NB 和 CAT1 二选一必选，**不能选错**

### 说明
当前产品主要应用于超声波户用测试，超声波分为有阀门版本和无阀门版本，也分为NB或者CAT1版本

## 三、测试指令（以5工位为例）

### 日志和透传控制指令 (0xAE/0xAF)
**开启日志不开透传**（查看程序状态0工位）：
```
68 AE 08 00 01 00 1F 16
```

**关闭日志和透传**（查看程序状态0工位）：
```
68 AE 08 00 00 00 1E 16
```

**开启日志不开透传**（查看程序状态5工位）：
```
68 AE 08 05 01 00 24 16
```

**开启透传不开日志**（使用国内水表指令工具5工位）：
```
68 AE 08 05 00 01 24 16
```

**同时开启日志和透传**（使用串口工具手动发送相关指令和水表交互）

---

### 查询当前测试步骤指令 (0xBE/0xBF) - 调试专用

用于查询当前测试流程停在哪一步 (`Test_liucheng_L`)，方便调试定位问题。

**协议格式：**
- 请求：`68 BE 06 [工位号] [校验和] 16`
- 响应：`68 BF [长度] [工位号] [步骤ID] [步骤名长度] [步骤名ASCII...] [校验和] 16`

**查询当前步骤（0工位）：**
```
68 BE 06 00 2C 16
```

**查询当前步骤（5工位）：**
```
68 BE 06 05 31 16
```

**校验和计算：** `68 + BE + 06 + 工位号`，取低8位

**行为说明：**
- **Debug模式开启时**：在日志打印当前步骤信息，同时发送协议响应
- **Debug模式关闭时**：只发送协议响应

**示例响应解析：**
```
68 BF 14 05 0A 0C "w_zoushui_CHK" XX 16
     │  │  │  │        │
     │  │  │  │        └─ 步骤名称(12字节ASCII)
     │  │  │  └─ 步骤名长度
     │  │  └─ 步骤ID (Test_liucheng_L 枚举值)
     │  └─ 工位号
     └─ 帧长度
```

**步骤ID对应表：**
| ID | 步骤名 | 说明 |
|----|--------|------|
| 0 | w_wait | 等待开始 |
| 1 | w_start | 开始测试(3.3V VCC测试) |
| 2 | w_reset_accumulated_flux | 设置累计流量 |
| 3 | w_close_valve_wait_response | 5线阀关阀等待响应 |
| 4 | w_qiehuan_kongshui | 切换为空水状态 |
| 5 | w_gonghao_CHK | 功耗测试 |
| 6 | w_qiehuan_manshui | 切换为满水状态 |
| 7 | w_gonghao_manshui_CHK | 满水功耗测试 |
| 8 | w_qiehuan_zoushui | 切换为走水状态 |
| 9 | w_gonghao_zoushui_CHK | 走水功耗测试 |
| 10 | w_read_accumulated_flux | 读取累计流量 |
| 11 | w_diancitie_huanxing_irda | 电磁铁唤醒红外 |
| 12 | get_biaohao | 获取表号 |
| 13 | get_banbenhao | 获取版本号 |
| 14 | set_famen_peizhi | 设置阀门配置 |
| 15 | w_zhudong_shangg | 主动上报 |
| 16 | w_shangg_jieguo_start | 第一次查询上报结果 |
| 17 | w_shangg_jieguo | 查询上报结果(期间检测阀门声音) |
| 18 | w_famenceshi | 阀门测试 |
| 19 | w_valve_test_process_1 | 阀门测试子流程-开始 |
| 20 | w_valve_output_voltage_check | 阀门输出电压检测 |
| 21 | w_water_temp_CHK | 水温检测 |
| 22 | w_end | 测试结束 |

## 五、重要提醒

### ⚠️ 必须注意的关键点：

1. **超声波表计类型必须选"二代管"** - 否则阀门配置会出错
2. **NB和CAT1不能选错** - 看清楚水表是什么型号
3. **有阀门和无阀门配置不同** - 主要区别在"阀门"和"阀门到位"两项
4. **测试指令不能用错** - 每种配置对应的指令都不一样
